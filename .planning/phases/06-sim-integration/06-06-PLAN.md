<objective>
Close RINT-04: deterministic E2E test in the Gazebo rover sim. Rover starts
in AUTO mode, picks up the largest person, follows the
walk_across_then_approach actor for the full walk pattern without losing
the target.

This mirrors the existing drone equivalent at
`test_sim_worlds.py::test_walk_across_then_approach_holds_target_through_approach`.
The rover version differs in:
  * Launcher: `sim/rover/start_rover_sim.sh` instead of `sim/start_sim.sh`.
  * App args: `--robot rover --config configs/rover_simulation.json` instead
    of `--takeoff-landing --connection udpin://...`.
  * Telemetry source: web-UI test_log JSONL captures the controller's
    bbox + mode + velocity per frame (same shape; the rover doesn't have
    MAVSDK telemetry but the controller path is identical).

The test is intentionally coarse-grained — gz sim is non-deterministic at
millisecond resolution, so the assertions check approach-window thresholds
(detection rate ≥80%, ID retention ≥80%, completion within timeout) rather
than exact frame-by-frame behavior.

Skip-if-not-installed for gz CLI + ROS 2 keeps the test portable. The
operator confirmed Phase 5 plumbing works on this dev box (see
.planning/phases/05-rover-sim/05-VERIFICATION.md), so the test SHOULD run
green here.
</objective>
