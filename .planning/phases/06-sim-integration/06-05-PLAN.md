<objective>
Close RINT-06: SIGINT shutdown integration test for the rover adapter.

The Phase 4 Ros2RoverAdapter.shutdown method is already correct (sets the
shutdown_event, joins the spin thread with timeout=2.0, destroys the node,
calls rclpy.try_shutdown(); idempotent). This plan adds tests that pin the
contract so future refactors can't silently regress it.

The RINT-06 acceptance shape:
  * Within 100 ms after SIGINT, ZERO further /cmd_vel publishes — translates
    structurally to "publisher is None or never called after shutdown returns".
  * Rover stops within 1 s — covered by the existing tests (publisher.publish
    isn't called with a non-zero Twist after the event fires).
  * rclpy node cleanly destroyed before rclpy.try_shutdown() — already pinned
    by test_shutdown_orders_node_destroy_before_try_shutdown in TestLifecycle.

This plan is test-only. No production code changes. The adapter shutdown
contract from Phase 4 is the thing under test.
</objective>
